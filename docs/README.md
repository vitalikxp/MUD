## Ключевые решения (кратко)

- Статический SPA на GitHub Pages. Сервера у нас нет, Cloud Functions не используются ([ADR-0001](adr/0001-static-spa-byok.md)).
- BYOK: ключ LLM приносит игрок. Запросы идут через stateless-relay на Cloudflare Worker из-за CORS ([ADR-0002](adr/0002-llm-relay-provider-agnostic.md)).
- ИИ пишет повествование, движок применяет механику через tool calls ([ADR-0003](adr/0003-llm-narrates-engine-decides.md)).
- Состояние хранится как журнал событий плюс проекции ([ADR-0004](adr/0004-event-sourcing.md)).
- Кооп с хостом-авторитетом: Мастер работает в браузере хоста ([ADR-0005](adr/0005-host-authoritative-coop.md)).
- Firestore для долговременных данных, RTDB для присутствия и живого стрима текста ([ADR-0006](adr/0006-firestore-plus-rtdb.md)).
- Правила подключаются модулями ([ADR-0007](adr/0007-modular-rules.md)). Первый модуль — OpenD6 с вариантами `fantasy` и `adventure` ([ADR-0011](adr/0011-opend6-first-module.md)).
- Секреты Мастера в коопе шифруются, ключ читает только хост ([ADR-0010](adr/0010-dm-secrets-encryption.md)).
- Лицензии: код — 0BSD, контент — CC0 1.0, модуль OpenD6 — OGL 1.0a ([ADR-0012](adr/0012-licensing.md), [ADR-0013](adr/0013-code-license-0bsd.md)).
- Книги OpenD6 (PDF) хранятся в git без LFS ([ADR-0014](adr/0014-reference-books-in-git.md)).
- TUI на DOM-сетке символов, стек Preact + Signals и Vite ([ADR-0008](adr/0008-dom-char-grid-preact.md)).
- Local-first: соло-кампании работают без Firebase, есть экспорт и импорт JSON ([ADR-0009](adr/0009-local-first-storage.md)).
