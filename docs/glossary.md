# Глоссарий

| Термин | Англ. (в коде) | Значение |
|---|---|---|
| Мастер, ИИ-мастер | DM | LLM + оркестратор, ведущий игру |
| Хранитель | Keeper / maintenance | Роль LLM для сводок и страховки лора после хода |
| Хост | host | Участник, в чьём браузере работает Мастер. Держит `hostLease` |
| Аренда хоста | host lease | Запись в Firestore, дающая право писать коммиты; продлевается каждые 30 с |
| Заявка | intent | Что игрок хочет сделать в раунде (текст или `pass`) |
| Раунд заявок | round | Сбор заявок всех игроков до одного ответа Мастера |
| Ход | turn | Один проход конвейера Мастера; даёт один коммит |
| Событие | event | Неизменяемый факт изменения состояния |
| Коммит | commit | Атомарная пачка событий хода |
| Проекция | projection | Текущее состояние, вычисленное из событий (`state/*`, `maps/*`, `lore/*`) |
| Черновик состояния | draft | Копия состояния, к которой применяются инструменты во время хода до коммита |
| Инструмент | tool | Функция движка, доступная LLM через tool calling |
| Модуль правил | rules module | Реализация `RulesModule` (напр. `opend6`) |
| Вариант правил | rules variant | Жанровый набор характеристик модуля (`fantasy`, `adventure`); выбирается шаблоном сеттинга |
| Код кубов | die code | Запись вида `3D+1`: сколько d6 бросить и сколько прибавить |
| Пип | pip | Надбавка +1 к коду кубов; 3 пипа = 1D |
| Wild Die | wild die | Выделенный куб броска: 6 взрывается, 1 даёт осложнение |
| Сложность | difficulty | Число, которое нужно выбросить (5, 10, 15, 20…) |
| Очки персонажа | Character Points (CP) | Тратятся на +1D к броску и на развитие |
| Очко судьбы | Fate Point (FP) | Удваивает кубы на одно действие |
| Очки тела | Body Points | Запас здоровья; уровни ранения дают штрафы |
| Шаблон сеттинга | setting template | Написанная автором заготовка мира в `content/settings/` |
| Канон | canon | Лор кампании; Мастер не противоречит ему без явного реткона |
| Лор-запись | lore entry | Сущность мира: NPC, локация, фракция, предмет, квест, факт |
| Реестр выборов | choice ledger | Значимые решения игроков и их последствия |
| Сессия ноль | session zero | Настройка кампании, развёртка мира и создание персонажей |
| Линии и завесы | lines & veils | Темы, которых нет в игре (линии) или которые остаются «за кадром» (завесы) |
| Палитра | palette | Набор цветовых токенов UI |
| Ячейка | cell | Одно знакоместо сетки TUI |
| Relay | relay | Stateless-прокси на Cloudflare Worker для обхода CORS |
| BYOK | bring your own key | Игрок использует собственный ключ LLM |
| Бытовое действие | UI action | Действие игрока без Мастера (экипировать, переложить) |
