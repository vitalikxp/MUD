# 09. Контент

## Шаблоны сеттингов

Шаблон — это **заготовка мира**, написанная человеком. Мастер разворачивает её в канон конкретной кампании во время сессии ноль
и дальше дописывает детали по ходу игры. Всё, что Мастер записал через `lore_upsert`, становится каноном этой кампании.

### Формат

```
content/settings/<id>/
  setting.yaml          # метаданные
  bible.ru.md           # «библия»: тон, темы, история мира, как вести игру в этом мире
  bible.en.md
  lore/*.yaml           # стартовые лор-записи (NPC, локации, фракции) — двуязычные поля
  scenarios.yaml        # стартовые сценарии (зацепки для первой сцены)
  maps/*.map.txt        # ASCII-карты заготовок + легенда
  bestiary.yaml         # (опц.) монстры сеттинга в формате модуля правил
```

```yaml
# setting.yaml
id: borderlands
version: 1.0.0
name: { ru: Пограничье, en: The Borderlands }
pitch: { ru: "Тёмное фэнтези на краю умирающей империи…", en: "..." }
genre: dark-fantasy
rules: { id: opend6, variant: fantasy }   # модуль и вариант правил шаблона
defaultPalette: terminal
paletteHints:                    # подсказки Мастеру, какие палитры уместны
  - { when: { ru: "подземелья и склепы", en: "..." }, palette: torchlight }
  - { when: { ru: "встреча с Туманом", en: "..." }, palette: void }
rating: 16+                      # по умолчанию; хост может понизить до 12+ или включить 18+
tone: [grim, mysterious, hopeful-at-the-edges]
```

```
# maps/crypt.map.txt
# legend: # стена, . пол, + дверь, ~ вода, A якорь "altar", E якорь "entrance"
####################
#......#....+.....#
#..E...#....#..A..#
...
```
Легенда задаёт тип клетки (проходимость, прозрачность, укрытие) и глиф. Якоря (`A`, `E`) потом используются в `place_token(anchor)`.

Валидация: zod-схемы в `src/content/schema.ts`, проверка в CI (`pnpm content:check`). Шаблоны импортируются в сборку как данные.

### MVP: два шаблона (Q2, решено)

| id | Жанр | Правила | Палитры | Зачем |
|---|---|---|---|---|
| `borderlands` «Пограничье» | тёмное фэнтези на краю умирающей империи | `opend6` / `fantasy` (с магией) | `terminal`, `torchlight`, `void`, `fey` | стартовый шаблон, на нём строятся evals |
| `ash` «Пепел» | постапокалипсис в духе Mad Max и Fallout: пустыня, топливо, банды на машинах, караваны, торговые города | `opend6` / `adventure` (без магии) | `amber`, `crimson`, `sepia`, `phosphor` | проверяет, что модуль, Мастер и UI не привязаны к фэнтези; больше боя и транспорта (правила транспорта: `adventure` p.56–58, p.121) |

Концепция «Пепла» выбрана (Q9). Подробная библия мира (история катастрофы, фракции, города, валюта) пишется в M5 по этому брифу.

## Сессия ноль

1. Хост выбирает шаблон, модуль, язык, рейтинг, линии и завесы, дополнительные пожелания («больше интриги, меньше боя»).
2. **Кузница мира** (Мастер, отдельный промпт) получает библию и лор шаблона, seed кампании и пожелания, а возвращает через инструменты:
   - 3–6 ключевых NPC и 2–3 фракции, конкретизированные для этой кампании;
   - главную угрозу или тайну (`visibility: dm`, `pinned`);
   - 3 зацепки и выбранную стартовую сцену.
3. Хост просматривает «видимую игрокам» часть и принимает её или перегенерирует (целиком или отдельную сущность).
4. Игроки создают персонажей. Кнопка «ИИ-помощь» предлагает концепты и предыстории под сеттинг.
5. Первая сцена: Мастер получает персонажей и стартовую сцену и открывает игру.

## Интернационализация

| Что | Как |
|---|---|
| Строки UI | `src/i18n/ru.ts`, `en.ts`. Типизированный ключ `t("panel.chronicle.title")`. Тест проверяет, что ключи совпадают |
| Контент модуля правил и шаблонов | Двуязычные поля `{ ru, en }`. Отсутствие перевода — ошибка `content:check` |
| Язык повествования | Параметр кампании (`narrationLang`), от языка UI не зависит |
| Лор, созданный Мастером | На языке повествования (одноязычный). Смена языка посреди кампании не поддерживается |
| Промпты | На английском с параметром языка ([04](04-ai-dm.md#промпты)) |
| Числа и даты | `Intl` с локалью UI |

## Лицензии контента

([ADR-0012](adr/0012-licensing.md))

- Собственный контент проекта (шаблоны сеттингов, палитры, промпты): **CC0 1.0** — без обязательного упоминания автора, коммерческое использование разрешено.
- Модуль `opend6` (`src/rules/opend6/`: механика, списки навыков, снаряжения, заклинаний, бестиарий, праймер для LLM): **OGL 1.0a**, как того требует лицензия источника.
  Шаблоны сеттингов ссылаются на модуль, но не копируют его текст, поэтому остаются под CC0.
- SRD 5.2 (будущий модуль): CC-BY-4.0, атрибуция обязательна.
- Шрифты: см. [07](07-ui-tui.md#шрифты), атрибуция в `NOTICE.md`.
