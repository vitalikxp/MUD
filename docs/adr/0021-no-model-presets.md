# 0021. Без пресетов моделей: одна модель по умолчанию и выбор из списка

- Статус: Accepted
- Дата: 2026-09-29
- Supersedes: пресеты «Экономный» / «Приватный» / «Качество» и выбор модели по умолчанию из [0017](0017-default-model-muse-spark.md). Раскрытие про обучение на данных и согласие участника из 0017 в силе.

## Контекст
Пресеты моделей дублировали окно выбора модели: игрок видел и строку «Модели» с тремя пресетами, и строку «Модель» со списком провайдера и нашими проверенными моделями.
Пресет тянул за собой связанные настройки (усилие рассуждений, согласие на обучение, модель Хранителя), поэтому выбор конкретной модели «поверх пресета» приходилось обрабатывать отдельно.
Проверка на реальных моделях (2026-09-29, [04-ai-dm.md](../04-ai-dm.md#проверка-на-реальных-моделях-2026-09-29)) показала, что модель по умолчанию из 0017 (`muse-spark-1.3-contributor`) играет хуже остальных.

## Решение
- **Пресетов моделей нет.** В настройках LLM (F4) остаётся строка «Модель»: окно выбора со списком провайдера и нашим реестром проверенных моделей (`verified`).
- **Модель по умолчанию у провайдера** (`ProviderPreset.defaultModel`, для OpenCode Go — `gpt-5.6-luna`, `reasoning.effort` = `medium`, `max_output_tokens` 4000). Это выбор из [0016](0016-default-models-pareto.md): самая дешёвая на фронте модель без обучения на данных, и она в нашей проверке лучшая по качеству игры.
  Для любой другой модели усилие рассуждений не задаётся (часть моделей на нём отвечает пустым текстом), лимит токенов берётся у модели по умолчанию.
- **Обучение на данных** определяется по признаку `contributor` в id модели. Такая модель показывает раскрытие и строку согласия; у модели по умолчанию их нет.
- **Модель Хранителя** отдельно не настраивается до M2 (в коде она пока не используется). Тогда же решим, нужна ли ей отдельная настройка.
- Порядок полей в форме: язык, провайдер, ключ API, «запомнить ключ», модель (или адрес, модель и формат у своего API), согласие на обучение, relay.

## Последствия
- + Одна настройка вместо двух, меньше состояний и веток кода.
- + Игрок по умолчанию не отдаёт свои тексты на обучение и не проходит через согласие.
- − Дешёвый вариант с обучением на данных (Muse Spark) больше не подсвечен; его можно выбрать в списке, он помечен «с оговорками».
- − Нет быстрого «режима качества»: `glm-5.3` выбирается в окне модели.
