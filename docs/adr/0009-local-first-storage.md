# 0009. Local-first: соло без Firebase, экспорт JSON

- Статус: Accepted
- Дата: 2026-09-28

## Контекст
Главная ценность — долговечность. Firebase-проект могут удалить или заблокировать, лимиты могут измениться.

## Решение
- Интерфейс `StorageAdapter` с двумя реализациями: `LocalAdapter` (IndexedDB) и `FirebaseAdapter`.
- Соло-кампании по умолчанию локальные, без аккаунта. Кооп-кампании облачные.
- Экспорт и импорт `.mud.json` с версионированным форматом. Перенос local → cloud делается через импорт.
- SDK Firebase загружается лениво, только для облачных кампаний.

## Последствия
- + Соло-игра работает при одной статике и ключе LLM.
- + Меньше начальный бандл.
- − Две реализации хранилища, общие контрактные тесты обязательны.
