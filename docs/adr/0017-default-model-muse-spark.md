# 0017. Модель по умолчанию — Muse Spark 1.3 Contributor

- Статус: Accepted
- Дата: 2026-09-28
- Supersedes: выбор моделей по умолчанию в [0016](0016-default-models-pareto.md). Методика и таблица из 0016 в силе.

## Контекст
В ADR-0016 `muse-spark-1.3-contributor` лежал на парето-фронте как самая дешёвая и при этом сильная модель (Elo 1906, $0.0016 за ход, ~37 000 ходов в месяц в лимите Go).
По умолчанию его не выбрали, потому что Meta обучается на запросах и ответах этого варианта. Владелец решил использовать Muse Spark.
В OpenCode Go Muse Spark есть только в варианте Contributor. Обычный Muse Spark 1.3 продаётся только в Zen ($1.25/$4.25).

## Решение
- **Мастер и Хранитель по умолчанию: `muse-spark-1.3-contributor`** (API `responses`). Для Хранителя он строго лучше `deepseek-v4.1-flash`: дешевле и лимит больше.
- Пресеты моделей в настройках:
  - «Экономный» (по умолчанию): `muse-spark-1.3-contributor` на обе роли;
  - «Приватный» (без обучения на данных): Мастер `gpt-5.6-luna`, Хранитель `deepseek-v4.1-flash`;
  - «Качество»: Мастер `glm-5.3`, Хранитель `deepseek-v4.1-flash`.
- **Раскрытие**: в настройках LLM, при создании кампании и в лобби видно, что Мастер работает на модели, которая отдаёт тексты игры на обучение Meta.
  В кооп-кампании участник подтверждает это при входе (флаг согласия в `members`). Не согласен — он может предложить хосту пресет «Приватный».
- **Регион**: если «Проверить» получает отказ по региону или по отсутствию согласия (opt-in в аккаунте OpenCode), UI предлагает переключиться на «Приватный».

## Последствия
- + Самая дешёвая игра при творческом Elo выше, чем у моделей того же ценового класса.
- + Одна модель на обе роли, настройка проще.
- − Тексты игр (включая реплики других игроков в коопе) уходят Meta на обучение. Смягчение — раскрытие, согласие и приватный пресет.
- − Бесплатная квота Contributor динамическая и не публикуется, вариант может исчезнуть. Смягчение — пресеты «Приватный» и «Качество» уже готовы.
- − Вариант доступен не во всех регионах и требует явного opt-in в аккаунте OpenCode.
