- Заменяет предварительный выбор Q5 (`kimi-k3` + `deepseek-v4-flash`): Kimi K3 оказалась самой дорогой моделью Go.

## Контекст
Мастер — прежде всего творческая задача, а игрок платит своей подпиской OpenCode Go. У подписки месячный лимит **на каждую модель** ($15, $30 или $60),
поэтому дорогая модель быстро упирается в лимит. Владелец попросил брать самые дешёвые модели на парето-фронте творческих навыков.

  получено 2026-09-28T19:49Z, SHA-256 `722ddb132e8d3a5e5c39b8d445f8475f3f7e24893a007260c6f3e3cce5c1ee18`.

**Модель стоимости хода Мастера:** 3 вызова (tool-loop) × (20k токенов из кэша + 4k новых на входе) + 1,5k токенов на выходе.

## Решение
- **Мастер по умолчанию: `gpt-5.6-luna`** — самая дешёвая модель на фронте без обучения на данных. Elo 1829, примерно в 14 раз дешевле `kimi-k3` за ход и примерно 2 800 ходов в месяц в лимите Go.
- **Хранитель по умолчанию: `deepseek-v4.1-flash`** — самая дешёвая по лимиту (~10 400 ходов в месяц). Для сводок творческий Elo вторичен.
- **Режим «Качество»** (пресет в настройках): Мастер `glm-5.3` — следующая точка фронта (Elo 2075, примерно в 7 раз дороже Luna).
- **`muse-spark-*-contributor`** доступны только по явному согласию игрока (галочка «Разрешаю Meta обучаться на моих играх»), с предупреждением,
  и **не для кооп-кампаний**: там в запросах тексты других игроков. По умолчанию не выбираются никогда. Модели недоступны в части регионов.
- Адаптер **OpenAI Responses переносится в M0**: он нужен модели по умолчанию. Anthropic Messages остаётся в M1.
- В M1 `eval:dm` проверяет кандидатов на русском языке и на надёжность вызова инструментов. Если модель не на фронте выигрывает по нашим evals, выбор пересматривается новым ADR.

## Последствия
- + Игра в 10–40 раз дешевле, чем с `kimi-k3`, и лимит Go почти не мешает.
- − EQ-Bench оценивает английскую прозу и не проверяет вызов инструментов. Для русского языка и tool calling решают только наши evals.
- − Цены и лимиты Go меняются. Таблица выше — снимок на 2026-09-28. Для пересчёта нужны свежие цены и бенчмарк.
