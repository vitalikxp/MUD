# 0005. Кооп с хостом-авторитетом и арендой

- Статус: Accepted
- Дата: 2026-09-28

## Контекст
Серверного кода нет (ADR-0001), а в кооперативе нужен единый Мастер: один вызов LLM на раунд, единый порядок событий.

## Решение
- Мастер работает в браузере хоста на его ключе. Только хост пишет коммиты и проекции (проверяется правилами Firestore).
- Право хоста — аренда `hostLease { uid, expiresAt }` в документе кампании, продлевается каждые 30 с (TTL 90 с).
- При истёкшей аренде любой участник с настроенным LLM может её перехватить транзакцией. Есть и добровольная передача.
- Вне боя ход идёт раундом заявок (один ответ Мастера на всех), в бою по очерёдности инициативы.

## Последствия
- + Никакой серверной логики, при этом всё консистентно.
- + Игра переживает уход хоста.
- − Хост платит токенами за всю группу.
- − Хост технически может жульничать (приемлемо, игра среди друзей).

## Альтернативы
- «Кто ходит, тот и Мастер» (распределённо): гонки, разные модели и промпты у разных игроков, сложная синхронизация. Отказ.
