# 0013. Лицензия кода — 0BSD

- Статус: Accepted
- Дата: 2026-09-28
- Supersedes: лицензию кода в [0012](0012-licensing.md) (Unlicense). Остальное из 0012 в силе: контент под CC0 1.0, модуль OpenD6 под OGL 1.0a, шрифты под своими лицензиями.

## Контекст
В ADR-0012 код получил Unlicense, а 0BSD была записана как запасной вариант: отказ от авторских прав (public domain dedication) признаётся не во всех юрисдикциях, в том числе в РФ.
Владелец решил сразу перейти на 0BSD.

## Решение
Код проекта распространяется под **BSD Zero Clause License (0BSD)**, SPDX `0BSD`. Текст лежит в `LICENSE`.

## Последствия
- + Это разрешение, а не отказ от прав, поэтому оно работает в любой юрисдикции. OSI-одобренная лицензия.
- + Без условий: не нужно сохранять копирайт и упоминать автора, коммерческое использование разрешено.
- − Строка копирайта в `LICENSE` формально есть (`SWRD contributors`), но сохранять её при использовании кода не требуется.
