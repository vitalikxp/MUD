# 0011. Первый модуль правил — OpenD6

- Статус: Accepted
- Дата: 2026-09-28
- Supersedes: выбор первого модуля в [0007](0007-modular-rules.md) (собственный `d20lite`)

## Контекст
Владелец решил использовать готовую открытую систему OpenD6 (https://opend6.net) вместо придуманного `d20lite`.
OpenD6 — открытая версия D6 System (West End Games), выпущенная в 2009 году под OGL 1.0a. Жанровые книги (D6 Adventure, D6 Fantasy, D6 Space)
различаются наборами характеристик, а первые два шаблона сеттингов проекта — фэнтези и постапокалипсис.

## Решение
- Модуль `opend6` с **вариантами**: `fantasy` (D6 Fantasy, с магией) и `adventure` (D6 Adventure, для постапокалипсиса). Шаблон сеттинга выбирает вариант.
- Механика: коды кубов (`3D+1`, 3 пипа = 1D), Wild Die, шкала сложности 5/10/15/20/25/30, Очки персонажа и судьбы,
  **Очки тела** (вариант «Уровни ран» — позже), готовый список заклинаний вместо конструктора.
- Все числа сверяются с книгами до написания кода (пометки ⚠ в 05-rules-engine). Упрощения записываются в раздел «Отступления от книги».
- Модуль распространяется под OGL 1.0a (ADR-0012).

## Последствия
- + Проверенная десятилетиями система, SRD со списками навыков, снаряжения, способностей.
- + Две жанровые книги — естественная проверка модульности на двух вариантах сразу.
- + Пул d6 с Wild Die даёт драматичные исходы (взрывы, осложнения), которые Мастер обыгрывает.
- − Ядру нужен бросатель пулов d6 с Wild Die, а интерфейсу `RulesModule` — варианты и тратимые ресурсы (`spendables`).
- − Магия D6 Fantasy тяжела для LLM, поэтому в MVP только готовые заклинания.
- − Лицензия OGL требует отдельного каталога и текста лицензии и запрещает использовать товарный знак «D6 System».

## Альтернативы
- Собственный `d20lite`: быстрее на старте, но это самодельные правила без проверки временем. Отменён решением владельца.
- D&D 5e SRD 5.2: больше данных, сложнее. Остаётся в бэклоге.
