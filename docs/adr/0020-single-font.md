# 0020. Один шрифт, без переключения

- Статус: Accepted
- Дата: 2026-09-29
- Уточняет: [0008](0008-dom-char-grid-preact.md) (там предполагалась альтернатива «чистый моноширинный») и [0019](0019-typescript7-oxlint-font-source.md)

## Контекст
В M0 были два шрифта: PxPlus IBM VGA 9x16 и JetBrains Mono (F3, команда `/font`). При переключении вёрстка выглядела плохо (замечание владельца):
сетка, рамки из псевдографики и шкала масштаба выверены под метрики пиксельного шрифта — ширина ячейки 9 px, высота 16 px, целочисленный масштаб.
У JetBrains Mono другие метрики (ширина 9,0/9,1 px при кегле 15, высота строки 19), швы `┌─┬─┐` и блоки `█▓▒░` стыкуются хуже, а хинтинг сглаживает края.
Проект ценит простоту (AGENTS.md §1) и атмосферу DOS.

## Решение
- Единственный шрифт — **PxPlus IBM VGA 9x16** (CC BY-SA 4.0). Смены шрифта нет: убраны F3, `/font`, настройка `font`, JetBrains Mono и пакет `@fontsource/jetbrains-mono`.
- Размер текста регулируется масштабом браузера (зум): сетка пересчитывается по размеру окна. Собственного масштаба и выбора шрифта в интерфейсе нет.
- Код метрик остаётся общим (`FONT`, `computeMetrics`): если когда-нибудь понадобится второй шрифт, это отдельное решение с проверкой стыков рамок на `/dev/glyphs`.

## Последствия
- + Меньше кода, меньше состояний и тестов; JS без лишнего CSS, нет шрифтовых файлов JetBrains в сборке.
- + Вёрстка гарантированно совпадает с выверенной сеткой.
- − Тем, кому тяжело читать пиксельный шрифт, поможет только зум браузера и палитра «высокий контраст».
