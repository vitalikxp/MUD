# 0007. Модульные правила, первым `d20lite`

- Статус: Accepted. Выбор первого модуля (`d20lite`) заменён [ADR-0011](0011-opend6-first-module.md); модульность в силе
- Дата: 2026-09-28

## Контекст
Хочется поддерживать разные системы (в перспективе D&D 5e SRD 5.2), но полноценный SRD — большой объём данных и механик,
и на нём долго ждать первой играбельной версии. К тому же LLM надёжнее применяет простые правила.

## Решение
- Ядро не зависит от системы правил. Правила подключаются реализацией интерфейса `RulesModule` (05-rules-engine).
- Первый модуль — собственный компактный `d20lite`: 6 характеристик-модификаторов, d20 против СЛ, 3 архетипа, уровни 1–5, бой на клетках.
- Модуль фиксируется в кампании по id и версии.

## Последствия
- + Быстрый путь к MVP и проверка архитектуры модулей на простом случае.
- + Праймер правил для LLM короткий.
- − Есть риск заточить интерфейс под d20. Проверяем мысленным экспериментом с 2d6-системой при ревью интерфейса.
- − Игрокам придётся выучить новую (простую) систему.
