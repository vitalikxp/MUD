# 0019. TypeScript 7 + oxlint вместо ESLint; источник шрифта PxPlus

- Статус: Accepted
- Дата: 2026-09-28

## Контекст
- Актуальный `typescript` — 7.0 (нативный компилятор на Go). `typescript-eslint` 8.71 требует `typescript >=4.8.4 <6.1.0`
  (peerDependencies, проверено 2026-09-28): ESLint с правилами для TS на TypeScript 7 не работает.
- Сайт автора шрифта `int10h.org` из среды разработки недоступен (таймаут и по HTTP, и по HTTPS).
- В PxPlus IBM VGA 9x16 нет символа `◆` (U+25C6), которым в документах помечались броски.

## Решение
- **TypeScript 7** (`tsc --noEmit` — проверка типов; сборку делает Vite).
- **oxlint** вместо ESLint: быстрый, без зависимости от компилятора TS, одна dev-зависимость.
  Проверки с учётом типов при необходимости подключаются через `oxlint-tsgolint` (работает с TS 7).
  В `.oxlintrc.json` отключены:
  - `react/immutability` — правило React Compiler, к Preact неприменимо (мутация `ref` в обработчиках — штатный приём);
  - `jsx-a11y/prefer-tag-over-role` — TUI рисует listbox, option и dialog в символьной сетке, нативные `<select>` и `<dialog>` туда не встраиваются;
    роли ARIA заданы явно, поведение — по паттернам WAI-ARIA.
  Точечные исключения — комментариями `oxlint-disable-next-line <правило> -- причина`.
- **Шрифт**: `WebPlus_IBM_VGA_9x16.woff` из The Ultimate Oldschool PC Font Pack v2.2 (VileR, CC BY-SA 4.0), взят из копии архива
  в Internet Archive (`oldschool_pc_font_pack_v2.2_FULL.zip`, SHA-1 `f9efb93551bf54923d2eae4c71928a974717c96b` совпал с метаданными архива).
  SHA-256 woff: `a1798e2f3d6d3dcb390116889a8e4a15163dd05b905c45df18b68b95c9282315`. Лицензия лежит рядом: `public/fonts/pxplus-ibm-vga/LICENSE.TXT`.
  Покрытие проверено `fc-query`: вся кириллица с Ё/ё, одинарные, двойные и смешанные рамки, блоки `█▓▒░▀▄▌▐`, `♦♥♣♠`, стрелки.
- **Маркер броска** — `♦` (U+2666) вместо `◆`.
- **«Широкие» символы** определяются по `\p{Emoji_Presentation}` и диапазону U+1F000–U+1FAFF, а не по `\p{Extended_Pictographic}`:
  в последний входят и однобайтные символы шрифта (`♦♥♣♠`), которые иначе заменялись на `?`.

## Последствия
- + Меньше зависимостей и быстрее проверки; стек совпадает с соседними проектами автора (TS 7).
- − Набор правил oxlint отличается от ESLint. Если понадобится правило, которого нет, — отдельное решение.
- − Шрифт хранится в репозитории: обновлять его вручную с проверкой контрольной суммы.
