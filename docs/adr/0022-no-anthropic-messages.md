# 0022. Два формата API: Chat Completions и Responses, без Anthropic Messages

- Статус: Accepted
- Дата: 2026-09-29
- Supersedes: часть [0015](0015-llm-three-api-formats.md), касающаяся адаптера Anthropic Messages (этап M1). Адаптеры Chat Completions и Responses из 0015 в силе.

## Контекст
ADR-0015 предполагал третий адаптер, Anthropic Messages, для моделей OpenCode Go, которые отдаются только в этом формате, и для прямого подключения к API Anthropic.
Подписка Claude (Pro и Max) не даёт доступа к API: нужен отдельный ключ с оплатой по факту использования, а вход по токенам подписки Anthropic разрешает только в своих продуктах. Значит, адаптер обслуживал бы только тех игроков, у кого уже есть платный API-ключ Anthropic, и несколько моделей Go, для которых есть замена в двух других форматах.

## Решение
- Адаптер Anthropic Messages **не делаем**. Клиент `src/llm/` работает с двумя форматами: OpenAI Chat Completions и OpenAI Responses.
- Модели, которые провайдер отдаёт только в формате Messages (сейчас у OpenCode Go: `qwen3.8-max`, `qwen3.7-plus`, `minimax-m3`, `minimax-m2.7`), в окне выбора помечены «нельзя играть», а «Начать игру» с такой моделью сообщает причину. Это существующее поведение (`unsupported`), оно остаётся.
- В настройках «своего API» формат выбирается из двух: Chat Completions и Responses. Провайдеры с родным API Anthropic подключаются только через их OpenAI-совместимый эндпоинт, если он есть.
- Пункт «Адаптер Anthropic Messages» убран из дорожной карты (M1).

## Последствия
- + Меньше кода и тестов, один этап M1 закрывается без работы.
- + Нет режима, который мог бы нарушить условия сервиса Anthropic.
- − Часть моделей Go недоступна игре, пока провайдер не откроет их через Chat Completions или Responses.
- − Игрок с API-ключом Anthropic не сможет подключиться напрямую (только через совместимый шлюз, например OpenRouter).
- Из relay убраны путь `/v1/messages`, хост `api.anthropic.com` и заголовки `x-api-key`, `anthropic-version`. Форки, которым нужен Anthropic, добавляют хост через `EXTRA_UPSTREAM_HOSTS`, но путь и заголовки придётся вернуть в коде.
