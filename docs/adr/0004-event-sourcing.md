# 0004. Журнал событий + проекции

- Статус: Accepted
- Дата: 2026-09-28

## Контекст
Нужны откат хода, перегенерация, отладка «что произошло», миграция хоста без потерь, экспорт и импорт,
а также сама история кампании как материал для памяти Мастера.

## Решение
- Источник истины — журнал коммитов (пачек событий). Состояние = свёртка журнала чистым редьюсером.
- Проекции (`state/*`, `maps/*`, `lore/*`) хранятся для быстрого чтения, их всегда можно пересчитать.
- Коммит содержит состояние RNG после применения, поэтому пересчёт детерминирован.
- Откат выполняется событием `revert`, физического удаления нет.

## Последствия
- + Откат, аудит, отладка, экспорт почти даром. Хроника — это просто отображение журнала.
- − Дисциплина: любое изменение состояния делается через новый тип события, типы событий нельзя ломать (нужны апкастеры).
- − Две записи (коммит + проекции) за ход, что учтено в бюджете Firestore.

## Альтернативы
- Хранить только текущее состояние: теряется история, откат сложен. Отказ.
