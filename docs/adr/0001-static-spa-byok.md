# 0001. Статический SPA на GitHub Pages + BYOK

- Статус: Accepted
- Дата: 2026-09-28

## Контекст
Проект должен жить годами без денег и без присмотра автора. Нужен ИИ, но у GitHub Pages нет серверного кода,
а Cloud Functions в Firebase доступны только на тарифе Blaze (привязка карты, риск счёта). Если ключ LLM зашить в статику,
его прочитает любой посетитель.

## Решение
- Сайт — статический SPA на GitHub Pages.
- Ключ LLM приносит сам игрок (BYOK), ключ хранится только в его браузере.
- Собственного backend с бизнес-логикой нет. Вся логика игры работает в браузере (у хоста).

## Последствия
- + Затраты $0, у автора нет ответственности за расходы на LLM и нет злоупотреблений его ключом.
- + Хостинг переносим на любую статику.
- − Порог входа: игроку нужен свой ключ. Смягчаем пресетами и понятной инструкцией.
- − Логика на клиенте, поэтому античита нет (приемлемо, см. 01-vision). Секреты Мастера шифруются от не-хостов (ADR-0010).

## Альтернативы
- Firebase Functions с ключом автора: нужен Blaze и карта, расходы растут с аудиторией. Отказ.
- Собственный VPS: платно, требует обслуживания. Отказ.
