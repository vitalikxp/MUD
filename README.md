
**SWRD** ([swrd.ru](https://swrd.ru)) — веб-сайт, где ИИ ведёт игру как Мастер (Dungeon Master) для одного игрока или кооп-группы.
Интерфейс — текстовый терминал в стиле Norton Commander. Механику исполняет детерминированный движок,
а ИИ рассказывает историю и вызывает инструменты движка.

- Статический сайт (GitHub Pages), Firebase на бесплатном тарифе, свой ключ LLM (BYOK).
- Любой провайдер с API в формате OpenAI или Anthropic: OpenCode Go, OpenRouter, Gemini, Anthropic, OpenAI, локальный Ollama.

Сайт: **https://swrd.ru** (пока не опубликован).

Правила: [OpenD6](https://opend6.net) (OGL 1.0a). Лицензии: код — 0BSD, контент — CC0 1.0, подробности в [NOTICE.md](NOTICE.md).
