# Карта тем OpenD6 для проекта

Где в книгах лежит правило, которое нужно проекту. Страницы — **страницы PDF** (печатный номер обычно на 1 меньше).
Формат: `книга p.N`. Открыть страницу: `python3 scripts/ref/search.py page <книга> <N>`.
Каталог книг: [INDEX.md](INDEX.md). Как пользоваться: [README.md](README.md).
